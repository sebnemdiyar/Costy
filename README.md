🛍️ Costy — Alışveriş Sitesi

Costy, modern bir kullanıcı arayüzüne sahip, duyarlı (responsive) bir alışveriş sitesi projesidir.
Bootstrap sınıfları ve component’ları kullanılarak sade, şık ve mobil uyumlu bir tasarım oluşturulmuştur.

🚀 Özellikler

Dinamik ürün listeleme

Ürün arama ve filtreleme özellikleri

Sepete ürün ekleme / çıkarma işlemleri

Toplam fiyat hesaplama

Responsive tasarım (tüm cihazlara uyumlu)

Temiz ve kullanıcı dostu arayüz

🧩 Kullanılan Teknolojiler

HTML5 

SCSS (Sass) 

Bootstrap 

JavaScript
